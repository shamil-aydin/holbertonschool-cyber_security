# 0x03 Protocols and Servers
0-iptables.sh: displays all current iptables rules with line numbers
1-audit.sh: checks non-standard SSH configuration settings
2-harden.sh: lists and secures world-writable directories
3-identify.sh: checks for vulnerabilities using lynis
4-nfs.sh: scans for NFS shares accessible by anyone
5-snmp.sh: finds SNMP configurations that allow public access
